# Support — McpGo

McpGo is currently a local reference installation being prepared for a public open-source project. A public issue tracker, community discussion channel, support SLA and release compatibility policy have not yet been announced.

For self-diagnosis see:
- [Getting started](docs/GETTING_STARTED.md)
- [Operations and recovery](docs/OPERATIONS.md)
- [Failure modes](docs/FAILURE_MODES.md)
- [FAQ](docs/FAQ.md)
- [Verification](docs/VERIFICATION.md)

Before public release, maintainers should publish supported macOS/Chrome/Node/Python versions, an issue template, discussion forum, clear triage labels and a separate confidential security channel.
