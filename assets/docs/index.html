Первое подключение

  1. Открой McpGo и выбери «Первое подключение».
  2. Пройди проверку macOS, затем укажи данные организации OpenAI Platform и разрешения для туннелей.
  3. Создай или подключи два отдельных Secure MCP Tunnel: для терминала и браузера.
  4. Подтверди доступ и установи локальные службы, затем разреши Chrome Remote Debugging.
  5. На странице ChatGPT Plugins добавь оба сервера и проверь работу инструментов реальным вызовом из чата.

Мастер не должен создавать ресурсы или запускать системные службы без явного подтверждения. Для повторного теста используй Dev Preview, а не пересобирай DMG после каждой правки.

Terminal MCP

Даёт ChatGPT возможность запускать разрешённые команды, читать результаты, работать с проектом и проверять сборки на твоём Mac.

Состояние Terminal и Secure MCP Tunnel смотри на главной панели. При ошибке сначала проверь журналы, затем перезапусти только соответствующую службу.

Личный Google Chrome

Playwright может подключаться к уже открытому личному Chrome. Открой в адресной строке браузера chrome://inspect/#remote-debugging и включи разрешение.

Статусы Browser MCP и доступности вкладок Chrome CDP проверяются отдельно: работающий MCP-сервер не означает, что Chrome уже ответил на команду просмотра вкладок.

Журналы и диагностика

Кнопка «Журналы» в боковом меню открывает папку ~/Library/Logs/McpGo через Finder. В ней находятся диагностические сообщения локальных служб и туннелей.

Если MCP не отвечает: проверь наличие запущенных служб на панели, разрешение Chrome, затем выполни повторную локальную проверку в мастере. Реальная доступность из ChatGPT проверяется отдельно.

Не отправляй в публичные отчёты API-ключи, секреты Service Account и личные данные из логов.
