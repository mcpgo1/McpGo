# MCP Hub — настройки двух Secure MCP Tunnels

Вкладка **«Настройки туннелей»** в нативном MCP Hub управляет существующими подключениями без редактирования файлов вручную.

## TerminalHub

- Tunnel ID — поле `control_plane.tunnel_id` в `~/.config/tunnel-client/chat-terminal-hub.yaml` (исходный профиль `chat-terminal-hub`). При изменении обновляется только значение поля, остальные параметры и внутренний MCP URL сохраняются.
- API-ключ — запись Keychain с service `com.chat-terminal-hub.openai.tunnel` и account пользователя macOS. Сохранённое значение никогда не подставляется обратно в поле.
- Туннель по-прежнему стартует через `terminal/run-tunnel.sh`, профиль `chat-terminal-hub`. Скрипт читает ключ из Keychain, tunnel-client — ID из YAML.

## Playwright

- Tunnel ID — `playwright/.cache/tunnel.id`, режим `0600`.
- API-ключ — новая запись Keychain с service `com.mcphub.playwright.openai.tunnel` и account пользователя macOS.
- До первого сохранения через настройки старый ключ может находиться в `playwright/.cache/tunnel.key` (права `0600`). При сохранении настроек ключ переносится в Keychain (если новый не указан), и после подтверждения сохранения устаревший файл удаляется.
- Рабочий запускатель `launchers/tunnel.mjs` и резервный `playwright/start-tunnel.sh` сначала читают ключ из Keychain; для совместимости до миграции допускают старый файл. Исходящий MCP endpoint остаётся `http://127.0.0.1:8940/mcp`, он не редактируется в UI, чтобы не открыть raw backend или сторонний URL.

## Порядок изменения

1. Ввести новый Tunnel ID (или оставить действующий), при необходимости вставить новый API-ключ в защищённое поле.
2. Нажать «Сохранить». Ключ не показывается и не записывается в текстовые логи. Сохранение само по себе не перезапускает рабочие соединения.
3. Нажать «Переподключить туннель» и подтвердить действие. Перезапускается только соответствующий `launchd` tunnel process. Если служба отключена, сначала запустите систему из «Обзор».
4. Проверить доступность из ChatGPT. Индикация «процесс запущен» не гарантирует, что внешний туннель успешно подключён.

**Важно:** переподключение TerminalHub кратко прервёт текущий доступ этого чата к Mac. Смена ID/ключа также требует соответствующего действительного туннеля и ключа в контрольной плоскости OpenAI; приложение не создаёт новые туннели автоматически.

Проверки: Native SwiftUI сборка, действующие источники конфигурации и статус Keychain, права файлов, синтаксис Playwright launchers, работа вкладки без сохранения реальных секретов. Никогда не добавляйте Keychain значения и файлы `*.key` в Git.
