# McpGo AutoSend — scheduled messages

**Текущий исполнитель:** `autosend/server.mjs` + `autosend/cdp-delivery.mjs`. Подключение к уже открытому личному Chrome через Playwright MCP safe proxy `http://127.0.0.1:8940/mcp`. Устаревший транспорт Chrome Extension/Native Messaging удалён из этой публичной копии; текущий маршрут доставки — только Playwright CDP.

## Работа пользователя

В нативной панели «Сообщения по таймеру» выбирают полный URL **существующего** разговора `https://chatgpt.com/c/UUID` либо разговора внутри ChatGPT Project `https://chatgpt.com/g/g-p-.../c/UUID`, текст (1–8000 символов) и период (60–604800 секунд). Новые расписания по умолчанию выключены и требуют явного включения.

## Доставка

1. Одновременно выполняется не более одной задачи, находящейся в состоянии проверки/отправки.
2. `browser_tabs(list)` возвращает список текущих вкладок. Исполнитель выбирает существующую вкладку с **точным URL**, либо открывает её.
3. Проверяет загрузку страницы, редактор, отсутствие неопределённости URL, существующего черновика и продолжающегося ответа.
4. При занятости или неготовности пропускает текущий интервал, не нажимая отправку.
5. Вводит текст без `submit`, снова проверяет URL, редактор, счётчики сообщений, текст и кнопку.
6. **Перед кликом** записывает `sending/click-committed` на диск; только после этого выполняет `browser_click`.
7. Наблюдает новую пользовательскую реплику. `verified` означает наблюдаемую отправку; это **не** подтверждение завершения работы агента.
8. После неопределённого результата — `pending/verifying`: дополнительные read-only проверки до трёх минут, без повторного клика. Только после истечения срока — `unknown` и ручная проверка.

## Данные

`~/Library/Application Support/McpGo/AutoSend/tasks.json` — текущий файл состояния, атомарная запись и приватные разрешения. В `/api/status` отображаются задания и последние попытки; журнал в интерфейсе можно очищать отдельно. Перезапуск процесса не означает автоматический повтор потенциально отправленного сообщения.

## Проверка

```bash
cd /path/to/McpGo/autosend
node --test tests/*.test.mjs
node --check server.mjs
node --check cdp-delivery.mjs
```

Автоматические тесты проверяют CDP по mock DOM, crash-safe recovery и изолированный HTTP server; реальная отправка в ChatGPT ими не подтверждена. Live-E2E — только в специально выделенном тестовом чате и после разрешения.

Подробнее: [AUTOSEND.md](../docs/AUTOSEND.md), [API](../docs/INTERFACES.md), [эксплуатация](../docs/OPERATIONS.md).

**Реализация подтверждения:** `reconciliation.mjs` и `cdp-delivery.mjs:reconcileViaPlaywright`. При перезапуске durable receipt сохраняется, а предыдущий текст пользователя не сохраняется — только SHA-256.
